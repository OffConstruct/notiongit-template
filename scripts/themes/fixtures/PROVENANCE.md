# Fixture image provenance

Every image under `scripts/themes/fixtures/*/assets/fixtures/` is listed here.
They are sample pictures for theme previews only. None shows a living person,
and none was taken from a stock photo site.

Each file is either in the public domain or was released under
[CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/) by the museum
that holds the original. The source column links to the Wikimedia Commons
file page, which records the holding museum and the license. Faithful
photographs of two-dimensional public-domain works carry no new copyright
(Commons "PD-Art"; *Bridgeman v. Corel*, 1999).

How the files were made: downloaded from Commons at up to 1800 px wide,
cropped to the size and aspect ratio the fixture content expects, and
re-encoded as baseline-progressive JPEG (quality 58) with Pillow. Re-encoding
drops all EXIF, XMP and ICC metadata from the download. `wide-dusk.jpg` is
scaled up about 11% from the downloaded width.

`portrait.jpg`, the sample profile picture of the fictional Rowan Vale, is a
crop of a painting from about 1880, not a photograph of a real person.

## Adding an image

1. Use only public-domain or CC0 sources whose license you can link to, such
   as a museum open-access release on Wikimedia Commons. Do not use stock
   photo sites: their licenses are not CC0.
2. Do not use photographs of living people.
3. Re-encode the file (for example with Pillow) so that no metadata from the
   download remains, and keep it under about 300 KB.
4. Add a row to the table above in the same change.
